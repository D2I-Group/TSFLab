# Audit

Maintenance module: confirm that code, catalogs, cards, admission records, and
Agent assets agree. Pick the narrowest scope; report failures rather than weakening a gate.

## Inputs

- The scope (one model, a model set, or the whole tree), the working tree, and the
  affected models when known.

## Steps

1. One model: follow [references/model.md](references/model.md) (metadata, source
   facts, implementation, admission), and show every discrepancy with file and line.
2. Fast checks after an implementation change: follow
   [references/smoke.md](references/smoke.md) for the narrowest smoke scope.
3. Whole repository: one gate. It refreshes the generated indexes, runs the static audits
   (cards, components, complexity, catalog, assets, docs), re-admits every model changed
   since `<ref>`, runs the affected smoke configs, and the tests; inspect the diff after:

   ```bash
   uv run tsf repo check --scope changed --base <ref>   # --scope release: every [admission] passed
   ```

   Full training belongs on GPU/CI. Check
   Agent assets and links (`.agents/README.md` is generated by `tsf repo cards`), flat
   models, shared components, card facts against runtime specs and presets (composition
   names only imported components, `data_params` match preset parameters), and public
   `tsf` instructions. Every model needs local code, a card in `tsflab.card/1`, and an
   `[admission]` record; a release needs every record `passed`. The strict contract
   covers construction, forward and backward, finite outputs and gradients, and the
   state-dict round trip.
4. For several models, audit each independently; the task owns partitioning,
   shared-file writes, and the final gate.

## Chain

- Module: Maintenance.
- Reads: cards (facts and `[admission]`), specs, presets, assets, and tests of every module.
- Produces: a gate result by layer; regenerated projections (`tsf repo cards`).
- Hands off to: `add-model`, `curate-components`, `diagnose-experiment`, `handle-contribution`.

## Success

- All audit sections PASS, no failed or pending admission in scope, and a clean
  `repo cards` diff; otherwise failures reported by layer: assets, card facts,
  source facts, paper/reference checks, admission, smoke, formatting, tests.

## Stop and hand off

- Report failures exactly; never hand-edit `[admission]`, fidelity, or claims to make
  counts pass; only `tsf model verify` writes admission records.
- Fixes go to `add-model` (single model), `curate-components` (cross-model),
  `diagnose-experiment` (run failures), or `handle-contribution` (an external change).
