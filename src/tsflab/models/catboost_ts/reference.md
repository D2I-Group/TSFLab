# CatBoostTS — reference

## Paper

- **Title**: CatBoost: unbiased boosting with categorical features
- **Venue**: NeurIPS 2018
- **Published**: 2018 (arXiv: 2017-06)
- **arXiv**: https://arxiv.org/abs/1706.09516

## Abstract

The paper presents the algorithmic techniques behind the CatBoost gradient-boosting toolkit.
Its two advances are ordered boosting, a permutation-driven alternative to the classic algorithm,
and a new algorithm for processing categorical features. Both fight a prediction shift caused by
target leakage present in existing gradient-boosting implementations.
