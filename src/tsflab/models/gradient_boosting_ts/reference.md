# GradientBoostingTS — reference

## Paper

- **Title**: Greedy function approximation: A gradient boosting machine
- **Venue**: Annals of Statistics, 2001

## Abstract (shortened)

Function estimation is viewed as numerical optimization in function space: stagewise additive expansions are linked to steepest-descent minimization, giving a general gradient-descent boosting paradigm for any fitting criterion.
Enhancements are derived for least-squares, least-absolute-deviation and Huber-M regression and multiclass logistic likelihood.
Regression trees are especially amenable to the approach, giving the Gradient Tree Boosting procedure, with robust, interpretable nonparametric models.
