# NBeats — reference

## Paper

- **Title**: N-BEATS: Neural basis expansion analysis for interpretable time series forecasting
- **Venue**: ICLR 2020 (arXiv 1905.10437, 2019-05)
- **Abstract (shortened)**: A deep architecture for univariate point forecasting built from backward and forward residual links and a very deep stack of fully-connected layers; interpretable, domain-agnostic, and fast to train. On M3, M4, and TOURISM it improves accuracy by 11% over a statistical benchmark and by 3% over the M4 winner. The generic configuration uses no time-series-specific components; the interpretable configuration constrains stacks to trend and seasonality bases with little loss in accuracy.
