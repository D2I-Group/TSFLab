# HimNet — reference

## Paper

- **Title**: Heterogeneity-Informed Meta-Parameter Learning for Spatiotemporal Time Series Forecasting
- **Venue**: KDD 2024, pages 631-641
- **arXiv**: https://arxiv.org/abs/2405.10800

## Abstract (shortened)

Fully capturing spatiotemporal heterogeneity remains a fundamental challenge. HimNet captures it implicitly by learning spatial and temporal embeddings (a clustering process), then learns spatiotemporal-specific parameters from meta-parameter pools informed by that heterogeneity. Experiments on five widely used benchmarks report state-of-the-art accuracy with interpretable embeddings.
